CenTRix has no server in this build. Accounts, sessions and records live only in this browser's local storage, so signing in keeps one store apart from another on the same device — it does not hide data from someone holding this device or browser profile. A seller and an owner using two different computers each get their own copy: cross-device sync is not enabled here.
